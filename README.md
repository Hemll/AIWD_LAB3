# AIWD_LAB3
Artificial Intelligence in Web Development Laboratory 3
Responsive Website Design using Bootstrap
Description

This experiment demonstrates the development of a responsive website using the Bootstrap framework. Bootstrap provides a mobile-first approach using predefined CSS classes, components, and a flexible grid system. The webpage layout is created using Bootstrap containers, rows, and columns, ensuring that the content adapts automatically to different screen sizes such as desktop, tablet, and mobile devices. Bootstrap components like navigation bars, buttons, and responsive images are used to build a consistent and responsive user interface without extensive custom CSS.
